OCR Pour l'alphabet Tifinagh

Réalisé par

Mohammed TALEB, Mohammed AOUKICHA et Zakaria BAOU

Description du Projet

Notre projet consiste à creer un OCR pour l'alphabet Tifinagh de la langue Amazigh en utilisant les convolutional neural network CNN. A partir d'une base de donnees d'image de lettres qu'on a creer via un script python.
